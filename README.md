# Erryka Garcia Portfolio

Static portfolio site: plain HTML, CSS and a little JavaScript. No build step.

## Files
- `index.html`: page content (projects, experience, skills, education, contact)
- `style.css`: all styling; colours are the variables at the top of `:root`
- `script.js`: copy-to-clipboard buttons in the Contact section
- `assets/photo.jpg`: profile photo

## Open in VS Code
1. Unzip the folder, then in VS Code choose File > Open Folder.
2. Install the "Live Server" extension, right-click `index.html`, then Open with Live Server.

## Publish on GitHub Pages
1. Create a repository, for example `pham-dham.github.io`, and push these files to the `main` branch.
2. In the repository, open Settings > Pages and set the source to the `main` branch, root folder.
3. The site goes live at `https://<username>.github.io/`.
